# DAEMON 504: Guardianes del Umbral
RPG web de exploración, captura y combate por turnos.
ISC-305 Programación Web · III PAC 2026

## Ramas
- main: solo versión estable (se entra con Pull Request)
- develop: integración del equipo
- feature/nombre-tarea: una rama por tarea

## Cómo trabajar
1. git checkout develop && git pull
2. git checkout -b feature/mi-tarea
3. Commits con prefijo: feat:, fix:, docs:
4. Subir la rama y hacer merge a develop
